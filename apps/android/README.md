# ToqueTin para Android

La app es opcional: un Android sin instalarla abre la web. Con la app instalada, un App Link abre el pedido y publica una notificación persistente; Android 16+ puede promoverla como Live Update.

Abre esta carpeta en Android Studio y ejecuta la tarea `testDebugUnitTest`. El proyecto usa `com.reinovalabs.toquetin`, apunta a `https://toquetinpro-web.onrender.com` y requiere JDK 17, SDK 36 y Android Gradle Plugin 8.13. El archivo local `app/google-services.json` es obligatorio y permanece excluido de Git.
